# Emotion-Aware Adaptive Tutoring for Autistic Learners: Experiments (C1–C4)

Code and results for the four experimental contributions of the PhD mini-thesis by **Asif Ali** (Sukkur IBA University).
The thesis asks whether an emotion-aware adaptive tutor for autistic learners is technically feasible. It tests each layer of a four-layer architecture (Perception → Interpretation → Fusion → Decision).

| Contribution | Question | Layer | Folder |
|---|---|---|---|
| **C1** Cross-domain FER benchmark | Do adult-trained FER models work on children and autistic children? | 1 Perception | `code/c1_benchmark` |
| **C2** Data-efficient adaptation | Which adaptation (CORAL, DANN, few labels, fine-tuning) closes the gap? | 1 Perception | `code/c2_adaptation` |
| **C3** Emotion → learning states | Can basic emotions predict boredom, confusion, frustration, disengagement? | 2 Interpretation | `code/c3_learning_states` |
| **C4** Affect–cognition fusion | Does adding affect to performance improve prediction and intervention decisions? | 3–4 Fusion, Decision | `code/c4_fusion` |

All experiments were run on a CPU workstation (8 logical cores, 16 GB RAM, no GPU).

## Key results

| | Result |
|---|---|
| C1 | ViT-S accuracy falls **0.56 (adult) → 0.41 (child) → 0.24 (autistic)**; predictions on autistic faces collapse onto *happy* and *angry*. |
| C2 | CORAL gives no gain; DANN (no labels) raises macro-F1 0.134 → 0.228 (3 seeds); fine-tuning with 25% / 50% autistic labels reaches 0.460 / 0.581. |
| C3 | A 7-d emotion vector predicts the four DAiSEE learning states with AUC 0.61–0.64, matching or beating a 128-d face embedding. |
| C4 | Affect adds only ~+0.001 AUC to next-answer prediction, but an emotion-aware rule catches **+5.3 pts** more upcoming failures (5/5 splits). |

Charts are in [`figures/`](figures/) and are regenerated by `code/figures/make_result_charts.py`.

## Repository layout

```
code/
  c1_benchmark/       make_child_subset.py (FER2013-Child), c1_pilot.py (frozen backbones + probe)
  c2_adaptation/      c2_embed.py (probes, CORAL, label budgets), c2_adapt.py (fine-tuning, DANN)
  c3_learning_states/ c3_extract.py (DAiSEE clip features), c3_classify.py (state classifiers)
  c4_fusion/          c4_pilot.py, c4_refine.py (fusion + rule engine), c4_dkt.py (DKT), c4_stats.py (5 splits, bootstrap)
  figures/            make_result_charts.py
results/              metrics (JSON/CSV), run logs, and actual.md summaries per experiment
figures/              result charts (Figures 5.1–5.6 of the thesis)
```

The final results used in the thesis are in `results/c1_cross`, `results/c2_real`, `results/c3` and `results/c4_full`.
`results/c1`, `results/c2` and `results/c4` are earlier pilot runs, kept for transparency.

## Data

The datasets are **not** included. Obtain them from their original sources under their own licences:

| Dataset | Used in | Source |
|---|---|---|
| FER2013 | C1, C2 | Goodfellow et al. (2013); Hugging Face / Kaggle mirrors |
| Autistic Children Emotions | C1, C2 | Public Kaggle dataset (Talaat, 2023) |
| DAiSEE | C3 | Gupta et al. (2016), on request from the authors |
| ASSISTments 2012–13 with affect | C4 | ASSISTments data portal (Pardos et al., 2014) |

**FER2013-Child** is derived by `make_child_subset.py`: a ViT age classifier (`nateraw/vit-age-classifier`) keeps faces with P(age 0–9) ≥ 0.9.

## Reproducing

```bash
pip install -r requirements.txt

# C1
python code/c1_benchmark/make_child_subset.py --fer data/fer2013 --out data/fer2013_age --thr 0.9
python code/c1_benchmark/c1_pilot.py --help

# C2
python code/c2_adaptation/c2_embed.py --help
python code/c2_adaptation/c2_adapt.py --help

# C3
python code/c3_learning_states/c3_extract.py --help
python code/c3_learning_states/c3_classify.py --help

# C4
python code/c4_fusion/c4_refine.py --csv <assistments.csv> --students 100000 --out results/c4_full
python code/c4_fusion/c4_dkt.py   --features results/c4_full/features.pkl
python code/c4_fusion/c4_stats.py --features results/c4_full/features.pkl --seeds 0 1 2 3 4

# Charts
python code/figures/make_result_charts.py
```

Each script's docstring and `--help` describe its arguments.

## Limitations

- The autism dataset is web-collected, with 6 classes and uncertain provenance; near-duplicates are controlled by perceptual hashing.
- Child labels come from an age classifier, not true ages.
- DAiSEE (college students) and ASSISTments (neurotypical middle-school students) are proxy populations; C3 and C4 validate mechanisms, not effectiveness for autistic learners.
